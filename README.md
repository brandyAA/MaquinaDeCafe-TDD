# Maquina de Cafe TDD

Proyecto desarrollado en Java utilizando TDD y JUnit.

## Funcionalidades

- Selección de vaso pequeño, mediano o grande.
- Selección de cantidad de azúcar.
- Validación de disponibilidad de vasos.
- Validación de disponibilidad de café.
- Validación de disponibilidad de azúcar.
- Pruebas unitarias mediante JUnit.
